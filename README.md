# 鬼計算

ニンテンドー3DS『鬼トレ』の鬼計算を参考にした、ブラウザ向け Nバック計算トレーニングです。

## 遊び方

1. バック数（1〜20）と速さ（ゆっくり / 速い）を選ぶ
2. 最初の N 問は覚えるだけ
3. 以降は画面の式ではなく、**N問前の答え**をテンキー（またはキーボード 0–9）で入力
4. 全20問終了後に正答率を表示（保存なし）

## 開発

```bash
npm install
npm run dev
```

## デプロイ（Vercel）

このリポジトリを Vercel に接続するか:

```bash
npx vercel
```

特別な環境変数は不要です。
